📚 Resumo dos 5 Métodos HTTP Implementados no Site

Método Rota REST Função no Site VoltScoot Onde Testar
GET GET /scooters e GET /scooters/:id Lista todas as Scooters Elétricas e abre o modal com a ficha técnica individual. Página Catálogo
POST POST /scooters Cria e cadastra uma nova Scooter Elétrica enviando o objeto JSON completo. Página Cadastrar / Editar
PUT PUT /scooters/:id Substitui/atualiza a ficha técnica completa de uma Scooter existente. Página Cadastrar / Editar
PATCH PATCH /scooters/:id Atualiza parcialmente apenas 1 campo (ex.: aplicar desconto no preço ou somar +1 no estoque). Página Promoções & Estoque
DELETE DELETE /scooters/:id Remove permanentemente uma Scooter Elétrica pelo seu ID. Página Promoções & Estoque
